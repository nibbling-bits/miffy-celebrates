# Miffy's Birthday Adventure — password-gated edition

## Secret word
The included default secret word is:

`princessmiftah`

To change it before uploading, open `script.js` and edit this line near the top:

`const BIRTHDAY_SECRET = "princessmiftah";`

Use lowercase letters/numbers for simplicity.

## Important privacy note
This is a lightweight JavaScript gate on a static website. It keeps casual visitors out,
but it is **not strong authentication**: a technical visitor can inspect the downloaded
JavaScript and discover/bypass the secret. No personal photographs are included in this package.

# Miffy's Birthday Adventure

GitHub Pages-ready static birthday website.

## Privacy
No personal photos are included in this package. The site uses CSS, emoji, and original text only.

## Publish
1. Create a GitHub repository named `miffy-birthday`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Go to Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/(root)`, then Save.
6. Wait for GitHub to show your live Pages URL.
